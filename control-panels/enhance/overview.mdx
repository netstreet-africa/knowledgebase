## Navigating the panel

When you log in to your Enhance panel, the left-hand sidebar is your primary navigation tool. Here is what each section does:

| Section | What it contains |
|---|---|
| **Websites** | All of your hosted websites; this is where you spend most of your time |
| **Emails** | Email account management, forwarders, aliases, and spam settings |
| **Logs** | Server and website access logs for debugging and auditing |
| **Packages** | View the resource quotas and feature limits assigned to your account |
| **Users** | Additional users who have access to your hosting account |
| **Integrations** | Connect Cloudflare, Slack, and other third-party services |
| **Settings** | Account-level settings including your control panel domain (resellers) |

<Info>
  If you are a reseller, you will also see a **Customers** section in your Primary Panel. This is where you create and manage the accounts that sit under your reseller account.
</Info>

## Supported applications

Enhance supports one-click installation for the following applications directly from the **Apps** tab of any website:

- **WordPress** — Full WordPress Toolkit integration with staging, SSO, and plugin management
- **Joomla** — One-click install with standard configuration
- **Node.js** — Deploy Node.js applications using the built-in deployment tool
- **Custom apps** — Any other application can be installed manually via File Manager or SSH

<Tip>
  If you want to deploy a Node.js application, navigate to your website in the panel, click **Advanced → Developer Tools**, and use the **Deploy Node.js** option. You can connect via SSH to install dependencies after deployment.
</Tip>

---

## Supported databases

Enhance fully supports both **MySQL** and **PostgreSQL**. You can create databases, manage database users, import and export SQL files, and access **phpMyAdmin** — all from the **Databases** tab within any website.

---

## Supported email clients

Enhance uses the same email infrastructure as cPanel-based plans. Your incoming and outgoing server settings remain unchanged:

- **Webmail**: Roundcube is included and accessible from the panel
- **IMAP / POP3 / SMTP**: Settings for iPhone, Android, Outlook, and Thunderbird remain the same as before
