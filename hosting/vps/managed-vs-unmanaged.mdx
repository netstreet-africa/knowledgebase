When you order a VPS from Netstreet Africa, one of the first decisions you'll face is whether to choose a **Managed** or an **Unmanaged** plan. The core difference comes down to a single question: who is responsible for keeping the server running, secure, and up to date? With a Managed VPS, Netstreet Africa handles the day-to-day administration so you can focus on your website or application. With an Unmanaged VPS, you take full control — and full responsibility — for everything that happens inside the server.

## What is a Managed VPS?

A Managed VPS is designed for customers who want their hosting provider to handle the heavy lifting of server administration. Netstreet Africa takes care of routine maintenance tasks so that you never have to log in to a command line if you don't want to.

Typical services included with a Managed VPS at Netstreet Africa include:

- Operating system installation and updates
- Security patch management
- Server monitoring and alerting
- Troubleshooting operating system issues
- Performance optimisation
- Backup management (where included in your plan)
- Technical assistance with supported server software

<Info>
  On a Managed VPS, Netstreet Africa's support team can assist with both the
  server infrastructure **and** operating system-level issues. You are not alone
  when something goes wrong.
</Info>

### Who should choose Managed VPS?

A Managed VPS is a strong choice if you:

- Prefer not to manage a Linux or Windows server yourself
- Run a business website or eCommerce store where uptime is critical
- Don't have a dedicated system administrator on your team
- Want Netstreet Africa to handle security patches and OS updates

---

## What is an Unmanaged VPS?

An Unmanaged VPS gives you full root access and complete control over your server environment. You decide what software to install, how to configure it, and how to secure it. This freedom comes with responsibility — you are accountable for everything that runs inside the server.

With an Unmanaged VPS at Netstreet Africa, you are typically responsible for:

- Installing and configuring the operating system
- Installing, updating, and removing software packages
- Applying security patches in a timely manner
- Configuring firewalls and access control policies
- Creating and managing your own backups
- Monitoring server performance and resource usage
- Diagnosing and fixing application or OS-level problems

<Warning>
  If you do not keep your Unmanaged VPS updated and secured, you leave it
  vulnerable to attack. A compromised server can affect not only your own data
  but the wider Netstreet Africa network. Please take server security seriously.
</Warning>

### Who should choose Unmanaged VPS?

An Unmanaged VPS is a better fit if you:

- Are a developer or experienced Linux/Windows system administrator
- Need a custom software stack or specialised server configuration
- Want the lowest possible monthly cost for your VPS
- Are comfortable managing updates, firewalls, and security yourself

## Frequently asked questions

<Accordion title="Does an Unmanaged VPS include any technical support?">
  Yes — but support is limited to the underlying infrastructure. Netstreet
  Africa will maintain the virtualisation platform, network connectivity,
  physical hardware, and ensure you have console access to your VPS. The
  operating system configuration, installed applications, and security inside
  the server remain entirely your responsibility.
</Accordion>

<Accordion title="Can I install my own software on a Managed VPS?">
  In most cases, yes. However, the level of customisation available and the
  software that Netstreet Africa officially supports may vary depending on the
  plan you have selected. If you need a highly customised stack, an Unmanaged
  VPS is likely a better choice.
</Accordion>

<Accordion title="Which option is right for beginners?">
  If you have little or no experience administering servers, a Managed VPS is
  the recommended option. An Unmanaged VPS requires you to be comfortable with
  the command line, package managers, firewalls, and security best practices.
  Starting with Managed and upgrading to Unmanaged later is always possible.
</Accordion>

<Accordion title="Can I switch between Managed and Unmanaged later?">
  Please contact the Netstreet Africa support team via your client area at
  my.netstreet.co.za if you would like to change your VPS management type. Our
  team will advise you on the best migration path for your situation.
</Accordion>
