# Source: https://kb.hosting.com/docs/lua

[Lua](http://www.lua.org/) is a flexible programming language frequently used for scripting.

- For shared and reseller hosting accounts, Lua is installed by default.
- For managed VPS or managed Dedicated Server plans, please open a ticket at [https://my.hosting.com](https://my.hosting.com) and we will install it for you.
- For unmanaged VPS, you can install Lua by using the package manager for your Linux distribution.
