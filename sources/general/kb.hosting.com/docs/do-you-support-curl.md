# Source: https://kb.hosting.com/docs/do-you-support-curl

Yes, we support cURL. The cURL command-line program is installed on our servers, and we compile cURL support into PHP as well.

## 

[​](https://kb.hosting.com/docs/do-you-support-curl#more-information)

More information

- For more information about the cURL command-line program, please visit [http://curl.haxx.se](http://curl.haxx.se).
- For more information about cURL support in PHP, please visit [http://php.net/manual/en/book.curl.php](http://php.net/manual/en/book.curl.php).
