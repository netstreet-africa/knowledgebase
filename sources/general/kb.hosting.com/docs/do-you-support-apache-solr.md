# Source: https://kb.hosting.com/docs/do-you-support-apache-solr

Apache Solr is an open-source search engine that requires Java. However, we do not support Java on our managed environments. Therefore, to use Apache Solr you must have an unmanaged VPS. This package provides you with root access and complete control over the operating environment.
