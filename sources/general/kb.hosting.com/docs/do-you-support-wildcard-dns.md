# Source: https://kb.hosting.com/docs/do-you-support-wildcard-dns

Yes, we support wildcard DNS for subdomains. To enable this, follow these steps:

1. Log in to cPanel.
2. In the **Domains** section of the cPanel home screen, click **Subdomains**.
3. Under **Create a Subdomain**, type `*` in the **Subdomain** text box.

 > 📘 Note cPanel automatically fills in the document root path by using the subdomain name that you provide. To use a different directory, type the full path in the **Document Root** text box.

4. Click **Create**.
