# Source: https://kb.hosting.com/docs/do-you-support-ioncube

Yes, we support ionCube PHP Encoder for shared and reseller hosting accounts by default. You can also dynamically load ionCube in a VPS.

On some shared and reseller hosting accounts, you must follow additional configuration steps to use ionCube Loader with non-default PHP versions. For more information, please see [this article](https://kb.hosting.com/docs/using-ioncube-loader-with-different-php-versions).
