# Source: https://kb.hosting.com/docs/do-you-support-the-imap-idle-feature

Yes, our servers support the IMAP IDLE feature for e-mail. IMAP IDLE enables servers to push notifications to e-mail client applications in real-time. For example, instead of an e-mail client occasionally querying the server to check if there are any new messages, with IMAP IDLE the server simply sends a notification to the client immediately after a new message arrives. This enables users to receive almost instantaneous notification of new messages and other changes to their mailbox.
