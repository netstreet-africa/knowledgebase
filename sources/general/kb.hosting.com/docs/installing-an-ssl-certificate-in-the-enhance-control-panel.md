Installing an SSL certificate in Enhance

**Important!**In many cases, you do not need to install an SSL certificate manually. For example, if you are using the free SSL certificate, it is installed automatically. Use this procedure only if you need to install an SSL certificate that you purchased from hosting.com or another provider.

## 

[​](https://kb.hosting.com/docs/installing-an-ssl-certificate-in-the-enhance-control-panel#install-an-ssl-certificate)

Install an SSL certificate

1. In the left sidebar, click **Websites**. ![](https://files.readme.io/228bef28a564fa447f4a92d5c208a9c69d68e7e5322737068090c99d2d6b34a5-image.png)
2. On the **Manage websites** page, click the website you want to manage.
3. Click the **Security** tab. ![](https://files.readme.io/39a2699551aeb5a9999c9ac429f6b276960590f467a5d58e3d49b04ee65149c3-image.png)
4. On the **Security** page, in the **SSL certificates** section, click **Install custom SSL**. ![](https://files.readme.io/c7c41407963207e7e4c2c4d6502dc70a83acfd09a2fa25ee005f38481bf3f970-image.png)
5. In the **Domain** list, select the domain where you want to install the SSL certificate.
6. In the **Certificate (CRT)** field, paste the certificate text. To upload the certificate file instead, click **Upload file**.
7. In the **Private key** field, paste the private key text. To upload the private key file instead, click **Upload file**.
8. Click **Upload**.

The Hosting Panel installs the certificate and private key for the selected domain.
