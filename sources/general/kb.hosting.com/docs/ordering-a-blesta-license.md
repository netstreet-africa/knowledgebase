# Source: https://kb.hosting.com/docs/ordering-a-blesta-license

This article describes how to order a Blesta license for a reseller hosting package.

## 

[​](https://kb.hosting.com/docs/ordering-a-blesta-license#about-blesta-licenses)

About Blesta licenses

A Blesta license enables you to install the customer management, billing, and support application on a reseller hosting package.

## 

[​](https://kb.hosting.com/docs/ordering-a-blesta-license#ordering-a-blesta-license)

Ordering a Blesta license

To order a Blesta license for your account, please open a billing ticket on the Hosting Panel at [https://my.hosting.com](https://my.hosting.com). After we process the order, you receive an e-mail message that contains the license key and instructions for [installing Blesta](https://kb.hosting.com/docs/blesta) .

## 

[​](https://kb.hosting.com/docs/ordering-a-blesta-license#more-information)

More information

For more information about Blesta, please visit [https://www.blesta.com](https://www.blesta.com).
