# Source: https://kb.hosting.com/docs/do-you-support-php-on-trax

Yes, we support PHP on Trax (formerly known as PHP on Rails). PHP on Trax is a PEAR module, so you can use the **pear list** command to see if it is already installed on your server.  If it is not installed, open a support ticket at [https://my.hosting.com](https://my.hosting.com) and we can install it for you.
