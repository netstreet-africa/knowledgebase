# Source: https://kb.hosting.com/docs/kernelcare

KernelCare is a software extension that allows us to update our kernel’s security on a daily basis without needing rebooting our servers. KernelCare is a key feature of our Perpetual Security initiative. KernelCare is included on each of our Web Hosting, Reseller Hosting, VPS Hosting, Managed VPS and Managed Dedicated solutions. The main advantages of KernelCare are:

- Fast updates.
- No downtime because no reboot is needed.
- Ensures kernel has latest security updates.
- Automatic security updates.
