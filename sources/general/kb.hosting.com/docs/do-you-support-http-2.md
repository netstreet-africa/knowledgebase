# Source: https://kb.hosting.com/docs/do-you-support-http-2

HTTP/2 is the next version of HTTP, the network protocol used by the World Wide Web. HTTP/2 is based on Google’s SPDY protocol, which is designed to improve web performance and security. The following account types currently support HTTP/2:

- Shared Web Hosting accounts.
- Turbo Reseller hosting accounts.
- Managed VPS and managed Dedicated Servers.

 > 📘 Note Some older servers may not have an HTTP/2-enabled web server version installed. To check whether or not your managed VPS or managed Dedicated server supports HTTP/2, please open a support ticket at [https://my.hosting.com](https://my.hosting.com).

- Unmanaged servers with Apache and **mod\_http2** installed.
- Unmanaged servers with LiteSpeed web server version 5 or later installed.

Additionally, HTTP/2 has the following requirements:

- Connections must use SSL. Although the HTTP/2 specification does not require encryption, Google Chrome and Mozilla Firefox only use HTTP/2 over an encrypted connection.
- Your visitors’ web browsers must support HTTP/2. For more information about HTTP/2 support in web browsers, please visit [https://en.wikipedia.org/wiki/HTTP/2#Browser\_support](http://en.wikipedia.org/wiki/HTTP/2#Browser_support).
