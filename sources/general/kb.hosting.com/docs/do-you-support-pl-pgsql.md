# Source: https://kb.hosting.com/docs/do-you-support-pl-pgsql

Yes, we support PL/pgSQL. All databases you create should have this functionality enabled. You do not need to use the **CREATE LANG** function. We will consider addition of other languages on a case-by-case basis. If you need further assistance, please open a support ticket at [https://my.hosting.com](https://my.hosting.com).
