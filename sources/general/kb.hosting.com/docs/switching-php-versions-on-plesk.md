# Source: https://kb.hosting.com/docs/switching-php-versions-on-plesk

This article describes how to use Plesk to change the active PHP version on an account.

Plesk is no longer included with new hosting.com plans, but it is still available on legacy Managed WordPress accounts. You can install Plesk manually on unmanaged VPS and Dedicated servers.

## 

[​](https://kb.hosting.com/docs/switching-php-versions-on-plesk#switching-php-versions)

Switching PHP versions

1. Log in to Plesk.

 > 📘 Note If you do not know how to log in to your Plesk account, please see [this article](https://kb.hosting.com/docs/logging-in-and-out-of-plesk).

2. In the left sidebar, click **Websites & Domains**: 
 ![Plesk - Sidebar - Websites and Domains](https://static.hosting.com/kb/kb-plesk-sidebar-websites-and-domains.png)
3. In options panel at the far right, click the **PHP Selector** icon. 
 ![](https://static.hosting.com/kb/kb_phpplesk_phpselector.PNG)
4. On the **PHP Selector** page, select the desired version of PHP from the **Current PHP Version** listbox and then click the **Set as current** button.![](https://static.hosting.com/kb/kb_phpplesk_phpversion.PNG)

## 

[​](https://kb.hosting.com/docs/switching-php-versions-on-plesk#switching-php-settings)

Switching PHP settings

1. Follow instructions 1 through 3 above to get to the **PHP Selector** page.
2. To add or remove PHP modules, select or clear the checkbox to the left of the module name.![](https://static.hosting.com/kb/kb_phpplesk_phpsettings.PNG)
3. To change other settings, start by clicking the **Options** tab near the top of the page. The **PHP Options** page will be displayed. 
 ![](https://static.hosting.com/kb/kb_phpplesk_phpoptions.PNG)
4. To change the settings, click on the setting value in the right-hand column, and enter or select the desired setting.
5. When each setting has been changed, a prompt will appear that states “Success, Module () saved.”
