# Source: https://kb.hosting.com/docs/do-you-support-the-mod_status-module

The **mod\_status** Apache module enables you to view real-time status information about a web server’s activity and performance. (To view the status page for the web server of the Apache project itself, you can visit [https://httpd.apache.org/docs/current/mod/mod\_status.html](https://httpd.apache.org/docs/current/mod/mod_status.html).) We do not support the **mod\_status** module on any of our managed hosting packages. However, you can install and configure the module yourself on any unmanaged product.
