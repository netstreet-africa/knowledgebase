# Source: https://kb.hosting.com/docs/do-you-support-ruby-on-rails

[Ruby on Rails](http://rubyonrails.org) is a web application framework that uses the Ruby programming language. Hosting.com supports Ruby on Rails, but the installation method depends on the type of hosting package that you have:

- On **shared, reseller, and Turbo managed hosting packages**, you must use the **Setup Ruby App** feature in cPanel to install Rails. For information about how to do this, please see [this article](https://kb.hosting.com/docs/configuring-a-ruby-on-rails-application-on-a-shared-hosting-account).
- On **unmanaged hosting packages**, you have root access and complete control over the server environment. You can install Ruby on Rails using the distribution’s package installation tools.
