# Source: https://kb.hosting.com/docs/do-you-support-varnish

[Varnish Cache](https://www.varnish-cache.org/) (often called simply “Varnish”) is a web application accelerator that uses caching to improve server performance, particularly during periods of increased site traffic. If you have an unmanaged hosting account, you can install and configure Varnish yourself.
