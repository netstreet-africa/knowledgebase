# Source: https://kb.hosting.com/docs/ssl-certificates

An SSL (Secure Sockets Layer) certificate enables your web site to send and receive data securely. It also enables you to prove your identity to visitors. For more information about how to obtain and install an SSL certificate for your web site, please see [these articles](https://kb.hosting.com/docs/ssl).
