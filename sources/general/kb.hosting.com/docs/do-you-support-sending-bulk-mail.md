# Source: https://kb.hosting.com/docs/do-you-support-sending-bulk-mail

No, we do not permit sending bulk mail directly from hosting accounts. However, if you want to send bulk mail for your web site, you can use a third-party service, such as:

- **iContact**: For more information about iContact, please visit [https://www.icontact.com](https://www.icontact.com).
- **Mailchimp**: For more information about Mailchimp, please visit [https://mailchimp.com](https://mailchimp.com).
- **SendGrid**: For more information about SendGrid, please visit [https://sendgrid.com](https://sendgrid.com).

- For all hosting products, the default message sending limit is one hundred (100) messages per hour. We can increase this limit up to one thousand (1000) messages per hour for **normal** email usage, but not for spam or bulk mail.
- Alternatively, if you have a large number of messages you want to send, you can use the following techniques to stay within the sending limit:
 - Spread out sending your email messages over a longer period of time.
 - Break up large recipient lists into smaller batches.
