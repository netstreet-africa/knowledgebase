# Source: https://kb.hosting.com/docs/do-you-support-mongodb

MongoDB is an open-source document database. Currently, MongoDB is only supported on the following user-managed hosting packages:

- Unmanaged VPS

This hosting package provides you with root access and complete control over the operating environment. We do not support MongoDB (including the php\_mongo module) on any managed hosting packages.
