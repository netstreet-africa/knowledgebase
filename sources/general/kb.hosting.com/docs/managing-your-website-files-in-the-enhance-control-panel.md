Managing your website files in the Hosting Panel

## 

[​](https://kb.hosting.com/docs/managing-your-website-files-in-the-enhance-control-panel#open-the-file-manager)

Open the File Manager

1. In the left sidebar, click **Websites**. ![](https://files.readme.io/228bef28a564fa447f4a92d5c208a9c69d68e7e5322737068090c99d2d6b34a5-image.png)
2. On the **Manage websites** page, click the website you want to manage.
3. Click the **Files** tab. ![](https://files.readme.io/ee5149c38bf28fb2a54fb3a916f3d1cb44594794deab8b2c973ce21d37481cb9-image.png)
4. The **File manager** appears. ![](https://files.readme.io/011610a06e737dd06cb014c47366479cedd934338e4d1646dbc22b34852bfac5-image.png)

## 

[​](https://kb.hosting.com/docs/managing-your-website-files-in-the-enhance-control-panel#navigate-your-files)

Navigate your files

Use the folder tree in the left sidebar to move through the file system:

- Click a folder name to view its contents in the right pane.
- Click the plus sign (**+**) icon to show subfolders under the current folder.

## 

[​](https://kb.hosting.com/docs/managing-your-website-files-in-the-enhance-control-panel#manage-files-and-folders)

Manage files and folders

In the right pane, you can perform these actions.

### 

[​](https://kb.hosting.com/docs/managing-your-website-files-in-the-enhance-control-panel#sort-items)

Sort items

To sort the listing by name, size, or last modified date, click a column heading. ![](https://files.readme.io/4f846609b5bf7a20606a2c05bde52051e9dc4936a887573651471758cb8bfd55-image.png)

### 

[​](https://kb.hosting.com/docs/managing-your-website-files-in-the-enhance-control-panel#create-a-file-or-folder)

Create a file or folder

1. Click **New**.
2. Click **File** or **Folder**.

### 

[​](https://kb.hosting.com/docs/managing-your-website-files-in-the-enhance-control-panel#upload-a-file-or-folder)

Upload a file or folder

1. Click **Upload**.
2. Click **File** or **Folder**.

### 

[​](https://kb.hosting.com/docs/managing-your-website-files-in-the-enhance-control-panel#modify-an-existing-file-or-folder)

Modify an existing file or folder

Right-click a file or folder, and then select one of these options:

- **Edit**: Edit a file.
- **Download**: Download a file to your local computer.
- **Get info**: View the path, size, permissions, and other details for a file or folder.
- **Copy**: Copy a file or folder.
- **Rename**: Rename a file or folder.
- **Compress**: Compress a file or folder.
- **Uncompress**: Extract a compressed file or folder.
- **Permissions (CHMOD)**: Change permissions for a file or folder.
- **Delete**: Delete a file or folder.

![](https://files.readme.io/e557caffc512d4f5d58fa7be01bfeb06bc73c8c9005869bad72d96f112cb6aad-image.png)

### 

[​](https://kb.hosting.com/docs/managing-your-website-files-in-the-enhance-control-panel#process-multiple-files-at-once)

Process multiple files at once

To perform actions on multiple files at the same time:

1. Select the **Select all** checkbox.
2. Choose one of the options that appears at the bottom of the page.

![](https://files.readme.io/d7f663619257d1b3141641840acddb970b63be7c5d46116dd6cc379d7986f13a-image.png) ![](https://files.readme.io/7f997fe1c6197cdc3486045cbd1fd2a78a31cb2d7acbc6b23d883b35c9044447-image.png)

**Important**Be careful when working with multiple files at once, especially when you are deleting items.
