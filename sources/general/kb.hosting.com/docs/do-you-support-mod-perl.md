# Source: https://kb.hosting.com/docs/do-you-support-mod-perl

No, we do not currently support the mod\_perl Apache module on shared hosting accounts. However, you can install mod\_perl on a dedicated server or VPS package.

**Important**At this time cPanel does not include mod\_perl in its latest Apache installer so we are unable to support it on managed servers. Please select our unmanaged VPS if you require mod\_perl.
