# Source: https://kb.hosting.com/docs/do-you-support-different-character-encoding-sets-for-postgresql

On shared hosting accounts, we do not support different character encoding sets for PostgreSQL. Unfortunately, due to limitations in cPanel, all user-created databases use a UTF-8 encoding scheme. If you require a different character encoding set for your PostgreSQL databases, you can upgrade to a VPS hosting plan. With a VPS, you have complete control over the PostgreSQL installation and configuration.
