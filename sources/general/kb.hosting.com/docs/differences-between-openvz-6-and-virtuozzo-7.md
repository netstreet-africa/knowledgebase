We are migrating Managed VPS accounts from the [OpenVZ](https://openvz.org/) 6 virtualization platform to [Virtuozzo](https://www.virtuozzo.com/) 7, resulting in significant performance increases. Learn more about the differences between these two virtualization platforms in this article.

## 

[​](https://kb.hosting.com/docs/differences-between-openvz-6-and-virtuozzo-7#differences-between-openvz-6-and-virtuozzo-7)

Differences between OpenVZ 6 and Virtuozzo 7

Virtuozzo 7 is based on OpenVZ, the open-source virtualization platform for Linux. In addition to the OpenVZ feature set, Virtuozzo adds additional features and functionality, including:

- Container and virtual machine backups.
- Software-defined storage.
- [ReadyKernel](https://docs.virtuozzo.com/virtuozzo_hybrid_server_7_users_guide/keeping-your-system-up-to-date/updating-kernel-with-readykernel.html): This feature enables the kernel to be updated without the need for rebooting.
- Automatic memory management policies: For more information, please visit [https://docs.virtuozzo.com/virtuozzo\_hybrid\_server\_7\_users\_guide/advanced-tasks/configuring-automatic-memory-management-policies.html](https://docs.virtuozzo.com/virtuozzo_hybrid_server_7_users_guide/advanced-tasks/configuring-automatic-memory-management-policies.html).
- Technical support.
- Updated installer.
- Different default package set.
