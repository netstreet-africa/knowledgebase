# Source: https://kb.hosting.com/docs/do-you-support-srs-sender-rewriting-scheme

Yes, SRS (Sender Rewriting Scheme) is enabled by default on all hosting.com servers (including A2 Hosting servers). You do not need to do any configuration on your part. When an email message is forwarded, the sending server uses SRS to modify the sender address. Doing so helps ensure that SPF (Sender Policy Framework) verification checks pass and the message is not rejected or marked as spam by the receiving mail server.
