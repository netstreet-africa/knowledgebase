# Source: https://kb.hosting.com/docs/do-you-support-cpanel-ssl

Yes, all new hosting.com accounts support cPanel SSL certificates. Using an SSL certificate from a recognized Certificate Authority is recommended for best results when enabling SSL. cPanel SSL certificates are free, automated, and are recognized by most modern browsers. cPanel SSL is supported for almost all new hosting.com accounts, and certificates may even be generated automatically for immediate use.

- cPanel-based Shared and Reseller hosting accounts have cPanel SSL enabled by default.
- Although cPanel SSL is enabled by default, there may be occasions when it cannot automatically generate an SSL certificate for an account. For more information, please see [this article](https://kb.hosting.com/docs/securing-a-cpanel-enabled-account-with-a-sectigo-ssl-certificate).
- For Managed VPS and Dedicated hosting accounts, you can request installation and activation from our Support team.
- For plans with root access and Unmanaged products, you can install and configure SSL yourself.

For more information regarding SSL certificates, please see the **Related Articles** section.
