# Source: https://kb.hosting.com/docs/do-you-support-headless-browsing-selenium-or-puppeteer

Headless browsing enables you to use a web browser without a GUI (Graphical User Interface). [Selenium](https://www.selenium.dev/) and [Puppeteer](https://pptr.dev/) are two popular Node.js libraries for interacting with headless browsers and automating web browsing. The following account types currently support headless browsing:

- Unmanaged VPS.
- Managed VPS and managed Dedicated Servers.

Headless browsing is resource-intensive, and therefore is not supported on other account types (such as shared hosting).
