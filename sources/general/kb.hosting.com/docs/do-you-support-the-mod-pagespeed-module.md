# Source: https://kb.hosting.com/docs/do-you-support-the-mod-pagespeed-module

The **mod\_pagespeed** Apache module is developed by Google, and is designed to reduce page load times and improve website performance. We can install **mod\_pagespeed** by request for the following account types only:

- Managed VPS (non-Turbo Boost accounts) **purchased before May 2025**.
- Managed Dedicated Server (non-Turbo Boost accounts) **purchased before May 2025**.

If you would like the **mod\_pagespeed** module installed on your server, please open a support ticket at [https://my.hosting.com](https://my.hosting.com).

**Important**Managed accounts with Turbo Boost do **not** support the **mod\_pagespeed** module. There are two reasons for this:

- The **mod\_pagespeed** module only works with the Apache web server, and Turbo Boost servers use the LiteSpeed web server.
- The LiteSpeed web server already includes the features of **mod\_pagespeed** . Even if it could be installed on Turbo Boost servers (which it cannot), doing so would be unnecessary and duplicate functionality.
