# Source: https://kb.hosting.com/docs/do-you-support-memcached-hosting

Memcached is an open-source memory object caching system that many websites use to help accelerate page load times. Memcached works by caching in RAM frequently accessed data, such as the results of API calls, database calls, and more. Memcached is available on the following hosting packages:

- All cPanel-based plans (shared, reseller, and managed VPS) purchased after April 2025.
- Managed VPS plans purchased before May 2025.
- Managed Dedicated server plans purchased before May 2025.
- Turbo shared hosting plans purchased before May 2025.
- Turbo reseller plans purchased before May 2025.

Of course, if you have an unmanaged VPS hosting account, you have root access and complete control over the operating environment. This enables you to install and configure Memcached yourself.

Alternatively, if you have a Managed VPS, Managed Dedicated Server, or unmanaged hosting account, you can run [Redis](https://kb.hosting.com/docs/do-you-support-redis), an in-memory caching system similar to memcached.
