# Source: https://kb.hosting.com/docs/do-you-support-the-pgcrypto-module

Yes, we support the _pgcrypto_ module, which provides cryptographic functions for PostgreSQL. It is not installed by default, but we can install it for you on shared, reseller, and managed dedicated servers by request. To do this, please open a support ticket at [https://my.hosting.com](https://my.hosting.com). Please include in your ticket the names of the PostgreSQL databases that you want to use with the _pgcrypto_ module. Of course, you can install the _pgcrypto_ module yourself on our unmanaged products.
