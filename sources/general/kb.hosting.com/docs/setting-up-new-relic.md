[New Relic Infrastructure](https://newrelic.com/products/infrastructure) is a third-party product that monitors server performance in real-time. For example, some of the things you can monitor include:

- Your server’s CPU and memory usage.
- Your server’s network usage.
- Your server’s disk usage.
- Specific user-defined events.

For detailed information about all of New Relic Infrastructure’s features and capabilities, please visit [https://newrelic.com/products/infrastructure/features](https://newrelic.com/products/infrastructure/features).

**Important**

- The information in this article only applies to Managed VPS accounts. You cannot use New Relic on shared or reseller hosting accounts.
- New Relic Infrastructure requires a paid license.

Setting up New Relic Infrastructure

To set up and use New Relic Infrastructure on your server, follow these steps:

1. Sign up for a New Relic account at [https://newrelic.com](https://newrelic.com) and obtain the following information:
 - Your license key.
 - Your account ID.
2. Open a support ticket at [https://my.hosting.com](https://my.hosting.com). In the ticket, please provide your license key and account ID. We must have this information to complete the installation process on your server.

 > 🚧 Important Do not try to install the New Relic agent yourself. The agent installation process requires root access, and must be done by hosting.com support.

3. After hosting.com support completes the installation process, you can use the New Relic Infrastructure dashboard to monitor your server.

 > 📘 Note For detailed information about how to use New Relic Infrastructure, please see the official documentation at [https://docs.newrelic.com/docs/infrastructure](https://docs.newrelic.com/docs/infrastructure).
