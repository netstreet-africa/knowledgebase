# Source: https://kb.hosting.com/docs/do-you-support-postgis

Yes, we support PostGIS on the following hosting packages:

- Managed and unmanaged VPS.
- Managed Dedicated servers.

- For information about how to determine if PostGIS is installed on your account, please see [this article](https://kb.hosting.com/docs/determining-the-postgresql-and-postgis-versions).
- PostGIS remains available on shared, reseller, and Turbo Web hosting packages on servers built **before** 2023.
