# Source: https://kb.hosting.com/docs/do-you-support-irc

IRC (**I**nternet **R**elay **C**hat) is an open-source communications protocol. Currently, IRC-related services are only supported on the following user-managed hosting packages:

- Unmanaged VPS

This hosting package provides you with root access and complete control over the operating environment. We do not support IRC-related services or communications on any managed hosting packages.
