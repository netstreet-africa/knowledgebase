# Source: https://kb.hosting.com/docs/do-you-support-the-rmagick-gem

Yes, we support the RMagick Ruby gem. Please see if it is already installed on your server by typing the following command at the command prompt:

```
gem list
```

If the RMagick gem is not installed, open a support ticket at [https://my.hosting.com](https://my.hosting.com) and we will install it for you.
