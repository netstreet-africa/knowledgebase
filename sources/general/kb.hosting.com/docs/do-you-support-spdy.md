# Source: https://kb.hosting.com/docs/do-you-support-spdy

SPDY (pronounced “speedy”) is a networking protocol developed by Google. It augments HTTP and is designed to improve performance. Currently, SPDY is only supported on the following user-managed hosting package:

- Unmanaged VPS

This hosting package provides you with root access and complete control over the operating environment.
