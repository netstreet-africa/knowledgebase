# Source: https://kb.hosting.com/docs/do-you-support-mapserver

No, we do not support MapServer on shared hosting accounts. MapServer has some complicated requirements that do not mesh well with a shared hosting environment. However, you can install MapServer on a dedicated server or VPS package.
