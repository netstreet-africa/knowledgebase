# Source: https://kb.hosting.com/docs/do-you-support-redis

[Redis](http://redis.io) (**RE**mote **DI**ctionary **S**erver) is an open-source data structure server. Redis is available on the following hosting packages:

- All cPanel-based plans (shared, reseller, and managed VPS) purchased after April 2025.
- Managed VPS plans purchased before May 2025.
- Managed Dedicated server plans purchased before May 2025.
- Turbo shared hosting plans purchased before May 2025.
- Turbo reseller plans purchased before May 2025.

Of course, if you have an unmanaged VPS hosting account, you have root access and complete control over the operating environment. This enables you to install and configure Redis yourself.

For information about how to set up and use Redis on managed hosting platforms, please see [this article](https://kb.hosting.com/docs/using-redis-on-managed-servers).
