# Source: https://kb.hosting.com/docs/do-you-support-dnssec

No, we do not support DNSSEC (Domain Name System Security Extensions). If you use hosting.com’s name servers for your domain, you cannot use DNSSEC. If you registered your domain with hosting.com and use other nameservers that support DNSSEC (such as Cloudflare), we can set up DNSSEC at the registrar level. Please [open a support ticket](https://my.hosting.com/) and provide the following information:

- DS Record
- Digest
- Digest Type
- Algorithm
- Public Key
- Key Tag
- Flags
