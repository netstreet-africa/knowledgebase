# Source: https://kb.hosting.com/docs/do-you-support-zip-files-with-php

Yes, all of our shared hosting accounts include PHP support for Zip files. You can verify this yourself by [using the phpinfo() function](https://kb.hosting.com/docs/view-php-settings) and searching for **—enable-zip** in the output. If you have a managed VPS or Dedicated server, and Zip file support is not already enabled, we can install it for you.
