This article is an introduction to the Plesk File Manager, and describes how to complete basic file management tasks.

Plesk is no longer included with new hosting.com plans, but it is still available on legacy Managed WordPress accounts. You can install Plesk manually on unmanaged VPS and Dedicated servers.

## 

[​](https://kb.hosting.com/docs/getting-started-with-the-plesk-file-manager#starting-file-manager-and-browsing-the-filesystem)

Starting File Manager and browsing the filesystem

The Plesk File Manager makes it easy to browse your web site’s directories and files. To start File Manager and navigate through the directory hierarchy on your account, follow these steps:

1. Log in to Plesk.

 > 📘 Note If you do not know how to log in to your Plesk account, please see [this article](https://kb.hosting.com/docs/logging-in-and-out-of-plesk).

2. Locate the domain for which you want to manage files, and then click **File Manager**: 
 ![Plesk - File Manager icon](https://static.hosting.com/kb/kb-plesk-file-manager-icon.png)
3. On the File Manager page, browse the directory hierarchy:

- To view a directory or file, click the directory or file name.
- To move up a level in the directory hierarchy, click the ![Plesk - File Manager - Uplevel icon](https://static.hosting.com/kb/kb-plesk-file-manager-uplevel-icon.png) icon.
- To expand a directory in the tree view, click the **+** icon.
- To collapse a directory in the tree view, click the **\-** icon.

Creating new folders and files

It is easy to create a new folder or file in File Manager. To create a new folder, follow these steps:

1. Log in to Plesk.

 > 📘 Note If you do not know how to log in to your Plesk account, please see [this article](https://kb.hosting.com/docs/logging-in-and-out-of-plesk).

2. Locate the domain for which you want to manage files, and then click **File Manager**: 
 ![Plesk - File Manager icon](https://static.hosting.com/kb/kb-plesk-file-manager-icon.png)
3. On the File Manager page, click **New**, then click **Create Directory**.
4. In the **Directory name** text box, type the name of the new directory (folder).
5. Click **OK**.

To create a new file, follow these steps:

1. Log in to Plesk.

 > 📘 Note If you do not know how to log in to your Plesk account, please see [this article](https://kb.hosting.com/docs/logging-in-and-out-of-plesk).

2. Locate the domain for which you want to manage files, and then click **File Manager**: 
 ![Plesk - File Manager icon](https://static.hosting.com/kb/kb-plesk-file-manager-icon.png)
3. On the File Manager page, click **New**, then click **Create File**.
4. In the **File name** text box, type the name of the new file.

Select the **Use the HTML template** check box to create the file with default HTML markup.

5. Click **OK**.

Copying, moving, renaming, and deleting files

To copy, move, rename, or delete files, follow these steps:

1. Log in to Plesk.

 > 📘 Note If you do not know how to log in to your Plesk account, please see [this article](https://kb.hosting.com/docs/logging-in-and-out-of-plesk).

2. Locate the domain for which you want to manage files, and then click **File Manager**: 
 ![Plesk - File Manager icon](https://static.hosting.com/kb/kb-plesk-file-manager-icon.png)
3. On the File Manager page, select the check box for the file (or files), and then do the file operation that you want:

- To copy a file, click **Copy**, select the destination directory, and then click **OK**.

 > 👍 Tip Select the **Replace existing files** check box to overwrite files with the same name in the destination directory.

- To move a file, click **Move**, select the destination directory, and then click **OK**.

 > 👍 Tip Select the **Replace existing files** check box to overwrite files with the same name in the destination directory.

- To rename a file, click the ![Plesk - File Manager - Dropdown icon](https://static.hosting.com/kb/kb-plesk-file-manager-dropdown-icon.png) icon, click **Rename**, type the new filename in the **New name** text box, and then click **OK**.
- To delete a file, click **Remove**, and then click **Yes** to confirm.
