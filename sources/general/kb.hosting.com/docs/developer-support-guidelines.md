Support guidelines for developer issues

Hosting.com provides web hosting and server technologies that make your website as stable and fast as possible. We pride ourselves on offering developer-friendly environments that run a variety of web applications and programming environments. However, this variety also means that there are a huge number of potential customer configurations. It is impossible for hosting.com to be experts in every application and technology. Therefore, hosting.com does not debug specific applications, plugins, or other issues directly related to coding on your site. We can assist you to the extent our of expertise, but you may need to consult external sources or an outside developer who specializes in the technology you use.

**Important**If you find specific evidence that a hosting.com server configuration or hosting environment is responsible for an issue you are experiencing, please open a support ticket at [https://my.hosting.com](https://my.hosting.com). In the ticket, please provide detailed instructions to reproduce the issue so our Advanced Support team can work on a resolution.

The following sections list several resources that you can use to help troubleshoot coding and application issues.

### 

[​](https://kb.hosting.com/docs/developer-support-guidelines#coding-resources)

Coding resources

We have an extensive collection of articles in our Knowledge Base to assist you with common development issues. To view these articles written specifically with the developer in mind, please click the “Developer Corner” section in the left sidebar. Popular programming languages also provide their own forums and online help, such as:

- **PHP:** [http://php.net/docs.php](http://php.net/docs.php)
- **Python:** [https://www.python.org/about/help](https://www.python.org/about/help)
- **jQuery:** [https://forum.jquery.com](https://forum.jquery.com)
- **Node.js:** [https://nodejs.org/en/docs](https://nodejs.org/en/docs)

Lastly, the [Stack Overflow](https://stackoverflow.com/) site is a good resource for developers. It has multiple forums that cover a wide range of programming languages and technologies. If all else fails, see if anyone else has discussed your problem on Stack Overflow.

### 

[​](https://kb.hosting.com/docs/developer-support-guidelines#application-resources)

Application resources

Our Knowledge Base has article collections devoted to the most commonly used web applications:

- [WordPress](https://kb.hosting.com/docs/wordpress)
- [PrestaShop](https://kb.hosting.com/docs/prestashop)
- [Joomla](https://kb.hosting.com/docs/joomla)
- [Drupal](https://kb.hosting.com/docs/drupal)
- [Magento](https://kb.hosting.com/docs/magento)

The quickest and easiest way to find relevant help in the Knowledge Base is to simply search for the terms you are interested in, such as “WordPress blank pages” or “PrestaShop caching”.

Each of these web applications also provides additional online resources:

- **WordPress:** [https://wordpress.org/support](https://wordpress.org/support)
- **PrestaShop:** [https://www.prestashop.com/forums](https://www.prestashop.com/forums)
- **Joomla:** [http://forum.joomla.org](http://forum.joomla.org)
- **Drupal:** [https://www.drupal.org/forum/18](https://www.drupal.org/forum/18)
- **Magento:** [https://community.magento.com](https://community.magento.com)
