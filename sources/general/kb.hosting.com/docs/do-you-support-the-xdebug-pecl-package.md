# Source: https://kb.hosting.com/docs/do-you-support-the-xdebug-pecl-package

We do not support the Xdebug PECL package, or any other PECL packages, on shared hosting accounts. However, you can install it on a dedicated server or VPS package.

## 

[​](https://kb.hosting.com/docs/do-you-support-the-xdebug-pecl-package#more-information)

More information

For more information about the Xdebug package, please visit [http://pecl.php.net/package/xdebug](http://pecl.php.net/package/xdebug).
