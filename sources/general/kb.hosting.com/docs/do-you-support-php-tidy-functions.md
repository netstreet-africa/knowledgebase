# Source: https://kb.hosting.com/docs/do-you-support-php-tidy-functions

Yes, we support PHP Tidy functions. Please [use the phpinfo() function](https://kb.hosting.com/docs/view-php-settings) to see if Tidy is already installed on your server. If it is not installed, open a support ticket at [https://my.hosting.com](https://my.hosting.com) and we will install it for you.
