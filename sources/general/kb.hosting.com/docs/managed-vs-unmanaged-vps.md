When choosing a Virtual Private Server (VPS), one of the first decisions you’ll need to make is whether to select a **Managed** or an **Unmanaged** service. The primary difference between the two options is **who is responsible for administering and maintaining the server**. A managed VPS transfers many day-to-day administrative tasks to the hosting provider, while an unmanaged VPS gives you full control over the server and requires you to manage it yourself.

# 

[​](https://kb.hosting.com/docs/managed-vs-unmanaged-vps#managed-vps)

Managed VPS

A Managed VPS is designed for customers who want the hosting provider to handle routine server administration and maintenance. This allows you to focus on your applications or websites instead of managing the operating system and server environment. Typical services included with a managed VPS may include:

- Operating system installation and updates
- Security patch management
- Server monitoring
- Troubleshooting operating system issues
- Performance optimization
- Backup management (if included with your hosting plan)
- Technical assistance with supported server software

A managed VPS is generally suitable for:

- Small and medium-sized businesses
- Website owners without server administration experience
- Production environments where reliability and reduced administrative effort are important

# 

[​](https://kb.hosting.com/docs/managed-vs-unmanaged-vps#unmanaged-vps)

Unmanaged VPS

An Unmanaged VPS provides full administrative (root) access and complete control over your server environment. You are responsible for configuring, securing, maintaining, and troubleshooting the operating system and installed software. With an unmanaged VPS, you are typically responsible for:

- Installing and configuring the operating system
- Installing and updating software
- Applying security patches
- Configuring firewalls and security policies
- Creating and managing backups
- Monitoring server performance
- Troubleshooting operating system and application issues

An unmanaged VPS is generally suitable for:

- Developers
- System administrators
- Experienced Linux or Windows server users
- Projects requiring custom software stacks or specialized configurations

Managed vs. Unmanaged VPS comparison

| Feature | Managed VPS | Unmanaged VPS |
| --- | --- | --- |
| Server administration | Hosting provider | Customer |
| Operating system installation | Hosting provider | Customer |
| Operating system updates | Hosting provider | Customer |
| Security patching | Hosting provider | Customer |
| Firewall configuration | Hosting provider | Customer |
| Backup management | Usually included (depending on the plan) | Customer |
| Performance monitoring | Hosting provider | Customer |
| Root access | No | Full root access |
| Technical support | Server administration and supported software | Underlying infrastructure and virtualization platform only |
| Monthly cost | Generally higher | Generally lower |

# 

[​](https://kb.hosting.com/docs/managed-vs-unmanaged-vps#which-option-should-you-choose)

Which option should you choose?

A **Managed VPS** is a good choice if you:

- Prefer not to manage a server yourself
- Need assistance with operating system maintenance and troubleshooting
- Want routine administrative tasks handled by us

An **Unmanaged VPS** is a better choice if you:

- Have experience managing Linux or Windows servers
- Require complete control over the server environment
- Need custom configurations or specialized software

**Frequently Asked Questions**

## 

[​](https://kb.hosting.com/docs/managed-vs-unmanaged-vps#does-an-unmanaged-vps-include-technical-support)

**Does an unmanaged VPS include technical support?**

Yes, but support is generally limited to the underlying infrastructure. This typically includes maintaining the virtualization platform, network connectivity, physical hardware, and ensuring console access to the VPS. Configuration, maintenance, and troubleshooting of the operating system and applications running inside the VPS remain the customer’s responsibility.

## 

[​](https://kb.hosting.com/docs/managed-vs-unmanaged-vps#%E2%80%8Bcan-i-install-my-own-software-on-a-managed-vps)

**[​](https://kb.hosting.com/docs/untitled-page#can-i-install-my-own-software-on-a-managed-vps)Can I install my own software on a managed VPS?**

In most cases, yes. However, the level of customization and the software supported may vary depending on our policy.

**Which option is right for beginners?**

If you have little or no experience administering servers, a managed VPS is generally the recommended option. An unmanaged VPS is better suited to users who are comfortable managing operating systems, security, updates, and troubleshooting on their own.
