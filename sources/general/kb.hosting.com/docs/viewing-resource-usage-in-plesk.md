This article describes how to view resource usage information in Plesk.

Plesk is no longer included with new hosting.com plans, but it is still available on legacy Managed WordPress accounts. You can install Plesk manually on unmanaged VPS and Dedicated servers.

## 

[​](https://kb.hosting.com/docs/viewing-resource-usage-in-plesk#viewing-resource-usage)

Viewing resource usage

To view resource usage information in Plesk, follow these steps:

1. Log in to Plesk.

 > 📘 Note If you do not know how to log in to your Plesk account, please see [this article](https://kb.hosting.com/docs/logging-in-and-out-of-plesk).

2. In the right sidebar of the Plesk home screen, click **Resource Usage**: 
 ![Plesk - Resource Usage icon](https://static.hosting.com/kb/kb-plesk-resource-usage.png)
3. After a few moments, the resource usage dashboard appears. Depending on your account’s resource usage, you may see:

- **Your site had no issues in the past 24 hours:** If you receive this message, your account did not trigger any limits within the past 24 hours.
- **Your site has been limited within the past 24 hours:** If you receive this message, your account triggered at least one resource limit within the past 24 hours. Plesk displays additional information about which resource (or resources) triggered the limit.
- **Your site might hit resource limits soon:** This message is a warning that your account may trigger resource limiting in the near future. Plesk displays additional information about which resource is at risk of triggering a limit.

4. To view detailed resource usage information for your account, click the **Details** button or click the **Current Usage** tab: 
 ![Plesk - Resource usage - Current Usage](https://static.hosting.com/kb/kb-plesk-resource-usage-current-usage.png)

Plesk displays usage graphs and a usage table for the current day. To change the time interval displayed, in the **Timeframe** list box, select the range of time to be displayed. In the **Time Unit** list box, select the interval between the data points to display: 
![Plesk - Resource Usage - timeframe options](https://static.hosting.com/kb/kb-plesk-resource-usage-timeframe-options.png)

5. To view a resource usage snapshot, click the **Snapshot** tab: 
 ![Plesk - Resource usage - Snapshot](https://static.hosting.com/kb/kb-plesk-resource-usage-snapshot.png)

Depending on your account’s resource usage, cPanel may display a list of processes and a list of HTTP queries:

- Use the arrow buttons to view snapshots in sequence.
- Use the calendar list box to select a specific date to view.
- Use the **Choose Snapshot** list box to select a specific snapshot to view.
