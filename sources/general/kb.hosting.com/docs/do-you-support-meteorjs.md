# Source: https://kb.hosting.com/docs/do-you-support-meteorjs

Meteor.js is a JavaScript web application framework designed for rapid application development. We do not support Meteor.js on any of our managed hosting packages. However, you can install and configure the module yourself on any unmanaged product.
