# Source: https://kb.hosting.com/docs/do-you-support-htmldoc-with-php

No, we do not support HTMLDoc. However, we can install the File\_PDF package from the PEAR repository by request. If you need further assistance, please open a support ticket at [https://my.hosting.com](https://my.hosting.com).
