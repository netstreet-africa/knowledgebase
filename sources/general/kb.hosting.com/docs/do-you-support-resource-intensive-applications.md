# Source: https://kb.hosting.com/docs/do-you-support-resource-intensive-applications

We do not support high CPU usage applications on shared, reseller, or Turbo Web hosting accounts. You may not run any audio or video encoding applications, such as _ffmpeg_, _fame_, or _lame_, on these accounts. If you want to run a resource-intensive application, you need a powerful server with root access. For the best performance, we recommend you use a managed Dedicated server with root access.
