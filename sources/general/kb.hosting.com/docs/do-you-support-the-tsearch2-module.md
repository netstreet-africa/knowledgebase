# Source: https://kb.hosting.com/docs/do-you-support-the-tsearch2-module

Yes, we support the tsearch2 module for PostgreSQL. Please check if this module has already been installed on your database. If not, you can open a support ticket at [https://my.hosting.com](https://my.hosting.com) and we will enable it for you. Please include the full database name in your ticket.
