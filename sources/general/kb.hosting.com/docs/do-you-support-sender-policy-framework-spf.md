# Source: https://kb.hosting.com/docs/do-you-support-sender-policy-framework-spf

Yes, we support SPF. You can enable SPF in cPanel. Please see **Related Articles** for more information. Additionally, we can add a custom SPF record to your DNS zone. If you need further assistance, please open a support ticket at [https://my.hosting.com](https://my.hosting.com). Make sure that you specify in the ticket the exact lines that you want to add to your zone file.
